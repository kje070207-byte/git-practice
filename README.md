# Git Practice

A small practice repository for the Open Source Software course.

## Topics
- Check repository status with `git status`
- Stage files with `git add`
- Save snapshots with `git commit`
- Review history with `git log`
- Ignore local and private files with `.gitignore`

## Basic workflow
```bash
git status
git add README.md
git commit -m "Update README"
git log --oneline
```

This repository contains examples for learning Git. It does not contain passwords, access tokens, or personal information.
